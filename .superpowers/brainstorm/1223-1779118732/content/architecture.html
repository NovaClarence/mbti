Component Architecture

App (Router)

React Router 管理三个阶段：首页 → 测试 → 结果。URL 驱动，支持前进后退

Scoring Engine (纯函数)

接收所有答案，输出 { type: "INTJ", dimensions: {...}, functions: {...}, reliability: {...} }

Question Engine

管理题库、版本筛选、出题顺序、防伪题插入。与评分引擎共享同一份题目元数据

Report Generator

评分结果 → 可视化报告。类型描述、维度分布图、八维雷达图

Test State (Zustand)

当前进度、已回答题目、已用时间。localStorage 持久化防刷新丢失

UI Components

ProgressBar、QuestionCard、OptionButton、TypeBadge、RadarChart、BarChart、ShareButton
